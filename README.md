# Nova Dashboard

A modern, responsive analytics dashboard built as a frontend portfolio project.

## Stack

- React
- TypeScript
- Vite
- Responsive CSS
- Component-driven UI

## Features

- Responsive dashboard layout
- Revenue analytics visualization
- Searchable recent orders
- Navigation state
- Dark mode
- Product performance cards
- Mobile-friendly table layout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Portfolio focus

This project demonstrates frontend architecture, semantic HTML, responsive layout, state management with React hooks, reusable UI patterns, and attention to accessibility-friendly interaction patterns.
